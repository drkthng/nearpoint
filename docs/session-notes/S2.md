# S2 — Trial engine and frame scheduler

## Built
- `src/core/trial.ts`: `buildTrial(spec, rand)` turns {condition, hz, durMs, isiMs} into whole-frame segments
  for a 2IFC trial; `expandFrames(plan)` gives one `FrameSpec` per frame
  (`phase`, `interval`, `showTarget`, `showFlankers`, `showFixation`). Helpers `isMasked`, `hasFlankers`,
  `maxJitterFrames`, `DEFAULT_TRIAL_TIMING`.
- `src/core/timing.ts`: `analyzeTiming(timestamps, hz, expectedFrames?)` flags late frames (> 1.5× nominal,
  strict), non-increasing/NaN timestamps and frame-count mismatches; never throws on bad data. `TrialTimingLog`
  = {hz, intended frames, timestamps, analysis}.
- `src/core/frame-patches.ts`: `framePatches(frame, layoutParams)` maps a frame to Gabor patches via
  `stimulusPatches` / `maskPatches` (S1).
- `src/app/player.ts`: `playFrames({frames, hz, drawFrame, drawEnd, raf?, signal?})` draws one frame per rAF
  callback, every frame, and resolves with a `TrialTimingLog`. No timers. Testable in Node with an injected rAF.

## Key decisions (all under "Our choices" in docs/protocol.md)
- Sequence: fixation 200 ms → blank 300 ms + jitter → interval 1 → gap 500 ms (offset of interval 1 to onset
  of interval 2) → interval 2. Response is outside the frame plan.
- Jitter uniform 0–250 ms in whole frames, max = floor(250·hz/1000), so never above 250 ms.
- ISI = blank between target offset and mask onset; mask duration = target duration.
- Fixation mark only during the fixation segment. Target interval 50/50 from the seeded RNG; `buildTrial`
  draws exactly two random numbers (target interval, then jitter).
- Timing log: N frames → N+1 rAF timestamps; t[k+1] − t[k] is how long frame k was on screen (presentation
  latency cancels). `drawEnd` runs in the final callback so the last trial frame is terminated and measured.
- Every frame of the trial counts towards the late-frame rule, not only stimulus frames.

## Tests
- 83 tests in 9 files (S2 added 42), about 2.6 s. Typecheck green.
- Published durations at 60/120 Hz (34/68/116 ms → 2/4/7 and 4/8/14 frames; ISIs 68/83/116/150 ms), segment
  order per condition, target in exactly one interval, flankers and masks in both intervals, jitter bounds at
  30/60/90/120/144 Hz with both ends reached, seeded determinism, analyser on synthetic timestamps (exactly
  1.5× is not late, NaN, late final frame), frame→patch consistency for all conditions, player order,
  drawEnd, error, abort and hz paths.
