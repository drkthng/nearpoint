# S6 — Outcome tests

## Built
- Pure core, separate from training (`src/core/outcome/`):
  - `optotypes.ts`: the 10 Sloan letters drawn by us as stroked centre-line SVG paths on a 5 × 5 grid
    (no font, so no licence issue); seeded letter draws without same-position repeats.
  - `acuity.ts`: logMAR geometry (letter height = 5 MAR, M-units, Snellen), lines that fit the screen,
    `AcuityProcedure` (start 0.7, up until a line has ≥ 4 correct, down until ≥ 3 errors), per-letter
    scoring (largest tested line + 0.1 − 0.02 × letters correct, floor/ceiling flags), `timedFrames`.
  - `reading.ts`: 16 original 10-word sentences, word wrap with injected measure, wpm, MNREAD-style
    reading acuity, critical print size and maximum reading speed, stop rule.
  - `contrast-test.ts`: own 2IFC frame list and 3-down/1-up `ContrastTestRun` for an isolated Gabor at 2/4/6 cpd.
  - `near-chart.ts`: printable A4 SVG chart (mm units, 100 mm check bar, logMAR/M/Snellen columns),
    letter orders A and B.
- Screens (`src/app/screens/outcome-*.ts`): `#tests` menu (tests, chart download/open, recent results),
  `#acuity?crowding=crowded|uncrowded&timing=unlimited|timed`, `#reading`, `#contrast`. Start screen
  has an "Outcome tests" button; History lists outcome results. All results go to the `outcomeTests` store.
- Docs: "Our choices" rows in `docs/protocol.md`; kinds and summary keys in `docs/data-dictionary.md`.

## Key decisions
- Letters drawn on a DPR-exact 2D canvas (black on white); lines below 5 device px letter height are not
  offered (at 40 cm on the S24 that is ≈ −0.2 logMAR).
- Time-limited letters: 300 ms fixation + 250 ms letters in whole frames via `playFrames`; a presentation
  with a late frame is repeated with new letters and its timing log is stored.
- Contrast test: no per-trial feedback; 200 ms intervals; timing-invalid trials do not move its staircase.
- Reading: onset = rAF timestamp of the draw, end = tap `event.timeStamp`; only sizes where every
  sentence fits in ≤ 3 lines are offered.
- `src/core/outcome/separation.test.ts` enforces non-negotiable 6 on imports (outcome code imports no
  training-engine values; training code imports nothing from outcome).
- Test hooks: `#acuity?...&auto=1`, `#reading?auto=1`, `#contrast?quick=1&auto=1&trials=N`; such rows
  carry `summary.testRun` and are hidden in History.

## Tests and verification
- 38 new unit tests (scoring, procedure incl. a 200-run probabilistic observer, reading metrics,
  contrast staircase with a 100-seed simulated observer: mean log threshold −1.417 vs −1.406 target,
  chart geometry, separation). `npm test` 193 tests, ~3 s; typecheck green.
- Headless Chromium (SwiftShader, 915×412 at DPR 2.625): all five auto runs complete and persist rows;
  screenshots of the letter line and a reading sentence checked by eye.

## Open issues
- Per-letter score estimates the 50 %-correct size + 0.05 logMAR (standard ETDRS convention; see test).
- Letters are Sloan-like, not a certified chart; time-limited and crowded variants are not normed.
- Reading font varies by device (Roboto on Android); the x-height is measured, but print-size
  comparisons across devices are approximate. Use the same phone for all tests.
- Not run on the Galaxy S24 yet.
