# S4 — Data layer

## Built
- `src/data/schema.ts`: row types (`Calibration`, `SessionRow`, `BlockRow`, `TrialRow`, `OutcomeTestRow`),
  `STORES`, `MIGRATIONS` (append-only; `SCHEMA_VERSION = MIGRATIONS.length`, currently 1).
- `src/data/db.ts`: `openDb({name?, factory?, migrations?, onBlocked?})` → `NearpointDb` with `add/put/get/all/
  byIndex`, `latestCalibration`, `sessionBlocks`, `sessionTrials`, `completedHistory()` (→ curriculum
  `SessionRecord[]`), `exportBackup(exportedAt)`, `restoreBackup(backup)`, `clearAll`. Plain IndexedDB, small
  promise helpers, no wrapper library. Connections close themselves on `versionchange`.
- `src/data/timing-record.ts`: trial timing logs stored compactly (intended frames run-length encoded as
  segments + N+1 timestamps + analysis), lossless round trip to `TrialTimingLog`.
- `src/data/csv.ts`: one CSV per table (`calibrations`, `sessions`, `blocks`, `trials`, `outcome_tests`),
  RFC 4180 writer and parser, segment encoding (`fixation:0:12:X;…`).
- `src/data/persist.ts`: `requestPersistence()` asks the browser not to evict site data.
- `docs/data-dictionary.md`: every CSV column with type, unit and description; backup/restore policy.
- Dev dependency: fake-indexeddb ^6.2.7, to test IndexedDB in Node (named in docs/sessions.md S4).

## Key decisions
- Auto-increment numeric ids; callers pass all timestamps (no clock inside the data layer → deterministic tests).
- Restore = replace everything in one transaction after validating every row; any failure aborts and leaves
  the old data untouched. Newer-schema backups are refused; older ones are restored as-is (future migrations
  must transform them).
- `TrialRow.valid` duplicates `timing.analysis.valid` for indexing and CSV; they must be equal.
- Optional fields reserved for S5 before any real data exists: `SessionRow.abortReason`, `rngSeed`,
  `appVersion`; `TrialRow.flankerContrast`.
- CSV: empty field = null (empty strings are not distinguished), booleans 1/0, lists `;`, CRLF, no BOM.

## Tests
- 126 tests in 17 files, about 2.7 s; typecheck and build green.
- Full-session round trip, history reconstruction and ordering, backup → JSON → restore identity, replace
  semantics, restore errors with data unchanged (bad format, newer/invalid schema version, missing store,

  connection is open, CSV quoting/parsing, timing round trip through CSV, dictionary ↔ code column sync,
  persistence outcomes.
