# S8 — End-to-end tests in CI

## Built
- `@playwright/test` (dev dependency, pinned to 1.63.0 = the browser build pre-installed in cloud
  sessions), `playwright.config.ts` (serves `dist/` with `vite preview`, Chromium with
  `--use-angle=swiftshader --enable-unsafe-swiftshader`), `npm run e2e`.
- `src/render/compare.ts` (pure, unit-tested): compares a frame with the CPU reference's ideal code
  values: grey, residual ≤ 1.05 codes, unbiased (frame and stimulus pixels, tolerance max(0.05, 5 SE)),
  16 × 16 block means within 0.35 codes. Detects wrong contrast, missing dither, mirrored images.
- `WebGLStimulusRenderer.readPixels()` and `debug.html?...&readback=1`: reads the GPU frame back in the
  draw task, compares it with `renderCpu()` and publishes `window.__nearpointDebug`.
- Specs (`e2e/`):
  - `render.spec.ts`: 8 cases (all six conditions incl. mask frames, four orientations, 0.4 % contrast,
    blank interval): shader compiles (WebGL2 renderer, no shader errors), GPU matches CPU statistically.
  - `training.spec.ts`: calibrate via UI, `#train?quick=1&auto=1&trials=6` with a 60 ms main-thread stall
    every 2.5 s; asserts N + 1 timestamps per trial, `valid === analysis.valid`, ≥ 1 valid and ≥ 1
    invalid trial, block valid/invalid counts match the trials, invalid trials never move the staircase
    (next trial keeps the contrast), block-end rule, invalid count shown on the summary.
  - `outcome.spec.ts`: auto runs of crowded acuity, uncrowded time-limited acuity, reading and quick
    contrast; stored rows, scores (0.3 logMAR from the auto responder), frame logs of timed
    presentations, test runs hidden in History; chart download.
  - `pwa.spec.ts`: installability, manifest, service worker control, cache contents, offline reload.
- CI: `e2e` job in `ci.yml` (after `test`): `playwright install --with-deps chromium`, build, test,
  uploads `test-results/` (screenshots per case) and `playwright-report/` as an artefact.

## Verification
- Local run in the cloud session: 13 tests pass in about 2.5 min (training session ~1 min).
- First local run found a false alarm at 0.4 % contrast (mean residual 0.074 over 248 pixels, sign
  varies across seeds = sampling noise): tolerance made sample-size aware.
