# S7 — PWA and deployment

## Built
- `public/manifest.webmanifest` (fullscreen, landscape, start_url/scope `./`, grey theme) and icons
  (`icon.svg`, PNG 192/512 and a maskable 512, rendered from the SVG: a Gabor patch on grey).
- Service worker generated at build time: `src/pwa/sw-source.ts` (pure, unit-tested) + a Vite plugin in
  `vite.config.ts` that lists every file in `dist/` after the build and writes `dist/sw.js` with a
  content-hash cache version. Install pre-caches the whole app; fetch is cache-first for same-origin GET
  only (ignoring `Vary`, since module scripts send `Origin`); navigations fall back to `index.html`;
  old caches are deleted on activate.
- `src/pwa/register.ts`: production-only registration; an update waits (no skipWaiting on install) and
  the start screen offers "Reload", ignored while a session or test runs.
- `src/app/wake-lock.ts`: Screen Wake Lock re-requested whenever the page becomes visible again (the
  browser drops it when hidden); used by training and the outcome tests. Landscape hint overlay in
  portrait during sessions/tests (`index.html`).
- README: Android (Galaxy S24, Chrome) install steps, secure-origin requirement, update and backup
  advice, deploy options (GitHub Pages workflow, Cloudflare Pages/Netlify for a private repo), PWA checks.

## Key decisions
- No runtime dependency (no Workbox): the worker is ~60 lines and only touches the app's own origin
  (non-negotiable 8).
- Lighthouse 12 removed the PWA category, so the PWA acceptance is checked directly in the e2e job
  (S8, `e2e/pwa.spec.ts`): `Page.getInstallabilityErrors` empty, manifest without errors, service worker
  controls the page, cache holds the app, offline reload renders the start and outcome screens.
- `deploy-pages.yml` reviewed: it uploads `dist/` (now including `sw.js` and the manifest); relative
  base `./` makes it work under `/<repo>/`. Not run from this session (manual trigger; Pages on a private
  repository needs a paid plan).

## Verification
- Unit tests for the worker source and manifest (install criteria, icons exist).
- Headless Chromium against `vite preview`: installability errors `[]`, offline reload works (first
  attempt failed on `Vary: Origin` → fixed with `ignoreVary`; then a boot-order bug: registration waited for
  `load`, which had already fired → fixed).
